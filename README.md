# Snake
English bellow

Jogo simples de Snake feito em Python com Tkinter, sem dependências externas.

## Como executar

```bash
python3 main.py
```

Clique em **Play** para começar. Use as setas ou **WASD** para controlar a
cobra. Ao terminar, escolha **Jogar novamente**, **Menu** ou **Exit**.

------------- English ---------------
A simple snake game built with Python and Tkinter, no external dependencies. 

## How to run
```bash
python3 main.py
```
Click in **Play** to start the game. Use the **arrows** or **WASD** to control the snake.
When finished, choose **Jogar novamente** (Play again), **Menu** or **Exit**.
